# Hirst Dot Painting Generator 🎨

A Python Turtle project that recreates Damien Hirst-style dot paintings using randomly generated colors extracted from an image.

## Features
- Generates colorful dot paintings
- Uses Python Turtle Graphics
- Random color selection
- RGB color palette extraction

## Technologies Used
- Python
- Turtle
- Colorgram.py
- Random Module

## Installation

pip install colorgram.py

## Run

python main.py
